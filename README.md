# 🎬 MovieWatch

A modern, responsive web application for discovering movies and TV shows. Built as a portfolio project to demonstrate modern front-end development practices, asynchronous API integration, and performance optimization.

🌐 **Live Demo:** [https://stanla21.github.io/MovieWatch/](https://stanla21.github.io/MovieWatch/)

---

## 🚀 Features

- **Movie & TV Show Discovery:** Browse trending titles, explore detailed descriptions, ratings, and cast info.
- **Dynamic Search:** Real-time search functionality with header integration.
- **TMDB API Integration:** Fetches real-time data dynamically using asynchronous JavaScript (`Fetch API` & `Async/Await`).
- **Responsive Layout:** Fully adaptive design optimized for mobile devices, tablets, and desktops.
- **High Performance:** Optimized static asset management and high Lighthouse scores.

---

## 🛠️ Tech Stack

- **Markup & Styles:** HTML5, SCSS (Sass)
- **Programming Language:** JavaScript (ES6+)
- **Build Tool & Bundler:** Vite
- **Data Source:** The Movie Database (TMDB) REST API
- **Deployment:** GitHub Pages (via GitHub Actions)
